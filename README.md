# Sayed Jehad World

A 3D side-scrolling interactive resume. Scroll (or hold ← →) and Sayed's avatar walks one continuous path through four realms. The world moves 1:1 with the wheel, he turns round when you scroll back up, and he stops when you stop.

1. **Desert**, "About me": who he is, the player stats, and Bahrain's heritage (Qal’at al-Bahrain, the Tree of Life, Arad Fort).
2. **Aqua**, "Road to Lumofy": he wades into the Gulf and swims past his education and every earlier role.
3. **Snow**, "Discipline Lab" and "AI Lab": out through a hole in the ice, skating, his values and skills, the current role, the live projects and the stack, then a cable car over the gorge.
4. **Magma**, "Dragon's Mountain": the certificates, then a climb over a sleeping dragon to the egg nest (the contact card) and the top.

A short loading screen builds all four realms first and then opens the world on its own. Planting the flag at the top wakes the dragon, which breathes fire into the fireworks. A little more scroll then brings in the contact card, still at the summit. Each realm has its own animals that react to him, its own sky, light, outfit, music and sound effects (sound is off until you switch it on). A plain-text "Quick resume" is one click away, "Pause animations" stops the ambient motion, Tab reaches every card, and a browser without WebGL gets the resume as text.

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:3000. `/lab/3d` (dev only) shows the character's animations and outfits. Stop the dev server before `npm run build`, because both use `.next`; `npm run build:local` and `npm run start:local` build and serve a production copy on port 3001 beside it.

## Check it

```bash
node scripts/qa-world.mjs
```

With a server running, this walks the whole world in headless Edge with the sound on, checks every way of moving and every sound trigger, saves screenshots to `test-results/world/` and prints frame times. Add `<outDir> 390 844` to run it as a phone, and `QA_URL=http://localhost:3001/` to point it at the production copy. `scripts/qa-world-extras.mjs` checks the server HTML, reduced motion, the no-WebGL fallback and the 404 page. `scripts/first-frame.mjs` remakes the opening shots and the share image.

## Rebuild the art

Everything 3D is generated by the Python scripts in `blender/scripts/` and exported to `public/world/` (`sayed.glb`, one `.glb` and one `.json` per realm). See `CLAUDE.md` for how to run them in Blender.

## Deploy

Built for Vercel: a push to `main` deploys. Set `NEXT_PUBLIC_SITE_URL` to the final domain if it is not the Vercel production domain (share previews, robots and sitemap use it).

## Stack

Next.js 16 (App Router) · React 19 · Tailwind CSS 4 · three.js with React Three Fiber and drei · Lenis · Blender 5.2 for the models. See `CLAUDE.md` for how the engine works.
